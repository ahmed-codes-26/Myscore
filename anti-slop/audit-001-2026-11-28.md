## Numbered Findings List

### 1. [HIGH] R-02 — Copywriting: Em Dash in Match Summary
- **Location:** `client/src/components/MatchSummary/MatchSummary.jsx:183`
- **Violated Rule:** R-02 (Copywriting — em dash forbidden in UI text)
- **Reason:** Text contains `Batting — {currentBattingTeam}`; replace em dash with colon (`:`) or parentheses.

### 2. [HIGH] R-02 — Copywriting: Em Dash in Player Profile
- **Location:** `client/src/components/PlayerPool/PlayerProfile.jsx:586`
- **Violated Rule:** R-02 (Copywriting — em dash forbidden in UI text)
- **Reason:** Empty bowling figure displays literal `—` character; replace with hyphen (`-`) or `N/A`.

### 3. [HIGH] R-02 — Copywriting: Em Dash in Scoring Screen Rules Banner
- **Location:** `client/src/components/Scoring/ScoringScreen.jsx:734`
- **Violated Rule:** R-02 (Copywriting — em dash forbidden in UI text)
- **Reason:** Banner text contains `Last Man Bats Alone — Solo Batsman faces every delivery`; replace em dash with colon (`:`).

### 4. [HIGH] R-39 — Accessible Semantics: Viewport Zoom Restriction
- **Location:** `client/index.html:5`
- **Violated Rule:** R-39 (Accessible Semantics & Document Structure)
- **Reason:** Viewport meta specifies `maximum-scale=1.0, user-scalable=no`, blocking accessibility zoom on mobile browsers.

### 5. [HIGH] R-32 — Keyboard Accessibility: Missing Escape Key Handlers on Modals
- **Location:** `client/src/components/Scoring/ScoringScreen.jsx`, `client/src/components/PlayerPool/AddPlayerModal.jsx`, `client/src/components/common/Header.jsx`
- **Violated Rule:** R-32 (Keyboard Accessibility)
- **Reason:** Dialogs, popup modals, and the mobile slide-out drawer do not listen for or close on `Escape` key press.

### 6. [HIGH] R-32 — Keyboard Accessibility: Focus Outline Stripped Without Replacement
- **Location:** `client/src/components/common/Header.jsx:50`, `client/src/components/MatchSetup/MatchSetup.jsx:335`
- **Violated Rule:** R-32 (Keyboard Accessibility)
- **Reason:** `focus:outline-none` is applied to interactive elements without a visible custom focus ring indicator.

### 7. [HIGH] R-39 — Accessible Semantics: Missing Global Interactive Cursor in Base CSS
- **Location:** `client/src/index.css`
- **Violated Rule:** R-39 (Accessible Semantics & Interaction Affordances)
- **Reason:** Base CSS layer does not define `cursor: pointer` on interactive controls (`button`, `select`, `summary`, `[role="button"]`), defaulting to standard arrow cursor.

### 8. [HIGH] R-39 — Accessible Semantics: Icon-Only Close Buttons Lack Accessible Names
- **Location:** `client/src/components/common/Header.jsx:196`, `client/src/components/PlayerPool/AddPlayerModal.jsx:87`, `client/src/components/Scoring/ScoringScreen.jsx`
- **Violated Rule:** R-39 (Accessible Semantics & Interaction Affordances)
- **Reason:** Close `✕` buttons lack `aria-label="Close"` attributes for screen readers.

### 9. [HIGH] R-39 — Accessible Semantics: CustomSelect Missing ARIA Combobox Semantics
- **Location:** `client/src/components/common/CustomSelect.jsx:54-85`
- **Violated Rule:** R-39 (Accessible Semantics & Interaction Affordances)
- **Reason:** Dropdown trigger button lacks `aria-haspopup="listbox"` and `aria-expanded`, and decorative SVG arrows lack `aria-hidden="true"`.

### 10. [HIGH] R-25 — Color Contrast: Low Contrast Gray Text on Light Backgrounds
- **Location:** `client/src/components/MatchSetup/MatchSetup.jsx`, `client/src/components/PlayerPool/PlayerList.jsx`, `client/src/components/Scoring/ScoringScreen.jsx`
- **Violated Rule:** R-25 (Color Contrast Standards)
- **Reason:** `text-slate-400` (#94a3b8) on white/slate-50 backgrounds yields ~2.4:1 contrast, failing the WCAG AA 4.5:1 minimum threshold; should be `text-slate-500` or `text-slate-600`.

### 11. [MEDIUM] R-11 — Border Radius: Uniform Over-Rounded 3XL Radius Across Components
- **Location:** `client/src/components/Scoring/ScoringScreen.jsx`, `client/src/components/MatchSetup/MatchSetup.jsx`, `client/src/components/MatchSummary/MatchSummary.jsx`
- **Violated Rule:** R-11 (Border Radius Consistency & Hierarchy)
- **Reason:** `rounded-3xl` (24px) is applied uniformly to outer cards, inner containers, banners, and modals rather than establishing a disciplined radius hierarchy.

### 12. [MEDIUM] R-12 — Elevation: Inconsistent Large Floating Shadows
- **Location:** `client/src/components/Scoring/ScoringScreen.jsx:883`, `client/src/components/common/Header.jsx:190`
- **Violated Rule:** R-12 (Shadow & Elevation Hierarchy)
- **Reason:** `shadow-2xl` is used on floating bars and drawer without an articulated elevation tiering system.

### 13. [MEDIUM] R-09 — Badges: Capsule Badge Trend Stacking
- **Location:** `client/src/components/MatchSummary/MatchSummary.jsx:87`, `client/src/components/PlayerPool/PlayerProfile.jsx:130`
- **Violated Rule:** R-09 (Badges & Status Elements)
- **Reason:** Status indicators combine pill shape (`rounded-full`), uppercase text, and micro font (`text-[10px] tracking-wider`) as a decorative pattern.

### 14. [LOW] R-31 — Craftsmanship Standard: Undocumented UI Decision Rationale
- **Location:** `client/src/index.css`
- **Violated Rule:** R-31 (Every Decision Must Have a Reason)
- **Reason:** Styling choices in base layer lack written one-line craftsmanship rationale.
